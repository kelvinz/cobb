# Official Design System Fit

Use when the brief maps to an official product ecosystem, under the load conditions in `references/design.md`. Prefer its established design system to a hand-built imitation.

- Microsoft or enterprise productivity: Fluent UI when the project can support it.
- Google or Material products: Material components/tokens when present or appropriate.
- IBM enterprise analytics: Carbon when already used or expected.
- Shopify admin: Polaris where applicable.
- Atlassian product work: Atlassian primitives/tokens when present.
- GitHub-style developer surfaces: Primer when present or explicitly requested.
- UK/US public-sector services: GOV.UK Frontend or USWDS.

Use one system per surface. Keep a different established system unless migration is explicitly in scope.
